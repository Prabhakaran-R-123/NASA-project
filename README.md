# 🌌 NASA Near-Earth Object (NEO) Tracking & Insights using Public API

 A python based project levering NASA's public APIs to fetch, analyse, and filter  data on near earth objects (NEOs) that may pose potential hazards to earth.

 # 🚀 Features

 - Fetch real-time and historical NEO data from NASA's Open API.
 - Analise asteroid size, speed, and close approach details.
 - Analyze trends in potentially hazardous asteroids.
 - getting the name of the asteroids which will pass closer to earth and the date by which it passes closer to earth.
 - counting how many approaches happened per month.
